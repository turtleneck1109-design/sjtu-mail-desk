交邮 v1.1 · 免安装 Python 的 Mac 应用

适用范围
Apple 芯片（M 系列）与 Intel 通用版，macOS 13 或以上。
应用已内置 Python、邮件处理组件和 TLS 根证书，不需要安装 Python、Node.js 或任何第三方包。

安装与使用
1. 打开 DMG，将“交邮.app”拖到“应用程序”；或解压 ZIP，移动交邮.app 到你喜欢的本机目录。
2. 双击“交邮.app”，会出现中文启动窗口，不会自动发送邮件。
3. 点击“体验演示模式”可打开带示例草稿的工作区。演示不会连接 SMTP，不需要真实密码。
4. 点击“打开邮件工作台”使用真实草稿；网页在系统默认浏览器中打开。
5. 所有发送仍要求预览、确认文字及密码。批量导入后请先核对收件地址和附件。
6. 关闭浏览器不等于退出后台。请回到交邮启动窗口，点击“退出交邮”或按 Command+Q。
7. 有任务正在提交时，退出会提示停止后续发送，并等待当前提交结束后保存结果。

首次打开的系统验证
此版本只有本地完整性签名（ad-hoc），没有 Developer ID 签名，也没有经过 Apple 公证。
从网络下载后，macOS 可能阻止首次打开，因此本版不保证下载后可以零提示运行。
若系统拦截，请先核实下载来源是本项目官方 GitHub，并按 macOS 提供的逐应用审核提示处理。
本工具不关闭或绕过系统安全保护，也不提供移除下载隔离标记的脚本。
如需无需额外人工审核的分发体验，需要后续完成 Developer ID 签名和 Apple 公证。

数据位置
启动窗口“打开数据文件夹”对应：
~/Library/Application Support/SJTUMailDesk/

正式模式使用 data/；演示模式使用 demo_data/。
数据保存在应用之外，替换或更新 .app 不会覆盖它们。
密码只保留在任务内存中，不写入文件。不要删除状态数据库后继续发送同一批草稿。

从 v1.0 源码版升级
应用不会擅自扫描或上传旧邮件，也不会自动迁移旧目录。
如果旧版已经发送过邮件，应在首次使用新版正式发送前迁移数据，以保留防重复发送记录：
1. 完全关闭旧版终端服务和交邮应用。
2. 将旧版 SJTU-Mail 文件夹里的整个 data 文件夹复制到上述 SJTUMailDesk 目录。
3. 目标已有 data 时，先保留备份并核对内容，不要合并两个不同的数据库。
4. 再启动新版，确认历史记录正确后使用。
只复制数据库或只复制 drafts 都不够；请完整保留整个 data 文件夹。

版本边界
本版使用用户提供的交大邮箱 SMTP 配置：mail.sjtu.edu.cn:465 / SSL/TLS。
服务器接受提交不代表最终送达；网页邮箱“已发送”没有记录也不能直接作为重发依据。
每个 .eml 文件最大 32 MB，一次最多确认 1000 封，默认发送间隔 2 秒。
测试与打包期间没有连接真实 SMTP，没有发送真实邮件。
