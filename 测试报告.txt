交邮 v1.0 测试报告
日期：2026-11-22（Asia/Shanghai）
环境：macOS，Python 3.14.4；Python 运行时只使用标准库。

结果：46 项自动化测试全部通过，0 失败。

1. 邮件逻辑和本机接口：33 项
   - 中文主题、To/Cc/Bcc、多收件人和 Excel 附件解析。
   - 空抄送和空显示组配合密送的合法邮件。
   - 缺失收件人、非法参数、超限文件、损坏 MIME 编码拦截。
   - 同内容不同文件名去重。
   - 预览、详情、确认清单不连接 SMTP。
   - 测试邮件仅投递指定测试地址，原 To/Cc/Bcc 不接收。
   - 正式模式 Bcc 只在信封中，出站邮件头不可见。
   - 中文正文、HTML 和附件解码字节保持一致，原 .eml 不被改写。
   - 成功记录跨重启及移除再导入继续去重。
   - 部分拒收时只重试失败地址。
   - 全部收件人拒收、发件人拒收、DATA 明确拒收归为明确失败。
   - 登录失败停止批次；提交前连接失败不标为未知投递。
   - 提交阶段断线锁定为待核对；人工解锁需指定确认文字并记审计记录。
   - SMTP 已接受后 QUIT 失败仍保留已接受结果。
   - 本地保存结果失败后停止，并锁定可能已接受的地址。
   - 上次中断的 attempting 记录启动时转为 uncertain。
   - 双击提交、两个标签页确认不能重复启动发送。
   - 停止后续发送允许当前一封结束，不启动余下邮件。
   - 发送期间不能导入或移除草稿。
   - 确认文字、过期清单和外部修改草稿均被检查。
   - CSV 防公式注入；临时测试密码不落盘。
   - HTML 预览移除活动内容、远程资源与跳转。
   - 附件下载与源文件内容一致。
   - 演示模式不调用网络连接，导出明确标记“模拟（未发送）”。
   - 本机 API 要求随机令牌，拒绝跨来源和非法 Host。
   - 静态资源策略、禁止任意路径访问、错误请求无副作用。
   - 导入→生成清单→确认模拟发送→读取结果→导出→移除完整接口流程。

2. Mac 启动入口：3 项
   - 实际通过 zsh 启动演示入口，使用中文及带空格的数据目录。
   - 实际启动正式入口，工作区为空且不发送邮件。
   - 同一工作目录第二次启动被进程锁拦截。
   两个 .command 均设置了可执行权限，均通过 zsh 语法检查。
   启动测试使用 --no-browser，未自动打开浏览器。

3. 离线界面逻辑：10 项
   - HTML 元素对应关系及默认勾选。
   - 搜索和状态筛选。
   - 单封测试按钮条件。
   - 确认清单显示实际收件地址并转义邮件内容。
   - 取消确认清空密码与清单。
   - 提交成功后清空密码。
   - 提交失败后清空密码并提示原因。
   - 发送期间禁用冲突操作。
   - 本机连接断开后禁用发送并提示重新启动。
   - 问题草稿可选中移除，但阻止批量发送。
   这些测试使用离线模拟页面元素，不属于实际浏览器渲染测试。

安全边界与未验证事项

- 全部发送测试使用模拟 SMTP 对象；没有连接交大邮件服务器，没有真实发送。
- 未验证真实账号认证、学校当前邮件配置、发送限流、最终送达和网页邮箱已发送归档。
- 访问本机页面的浏览器预览被权限检查拒绝；没有绕过该限制。
- 未完成真实浏览器的视觉、响应式排版、实际点击及附件下载体验验收。
- 已测试启动命令的实际服务启动；Finder 双击及系统安全提示未做目视验收。
- Python 3.9 为代码最低目标版本，本次实际验证版本为 Python 3.14.4。
